# 范围
学生卡的使用场景包括:
 - 淋浴间水卡
 - 食堂饭卡
 - 刷开图书馆预约空间
 - (隐藏): 管理员手动添加后可刷开学院房间

# 如何充值
学生卡已升级至ecard 2.0, 在上财微门户里的 应用 -> 财务资产 -> 一卡通2.0 -> 一卡通服务 -> 充值

# 如何用水
学生卡已升级至ecard 2.0, 在上财微门户里的 应用 -> 财务资产 -> 一卡通2.0 -> 一卡通服务 -> 生活用水

# 挂失怎么办
前往大学生活动中心(武东路操场西面),进门右转寻找补办窗口即可

# TIPS
考试时携带学生证本或身份证, 学生卡原则上不用作身份证明
