# 上海财经大学关于2026年硕士研究生调剂复试工作公告

根据教育部有关文件精神，结合我校报考实际，现将我校2026年硕士研究生调剂复试工作的有关事项公告如下：
一、接受调剂的专业
| 学院 | 专业 | 研究方向 | 学习方式 | 
| 上海国际金融中心研究院 | 金融硕士 | 资产与财富管理 | 非全日制 | 
| 滴水湖智库 | 金融硕士 | 金融与人工智能应用 | 非全日制 | 
| 数理经济学教育部重点实验室 | 金融硕士 | 大数据金融 | 非全日制 | 
| 商学院 | 工商管理硕士 | 工商管理（综合精英）、工商管理（创投）、高级管理人员工商管理硕士（金融） | 非全日制 | 
| 滴水湖高级金融学院 | 工商管理硕士 | 新金融 | 全日制 | 
| 工商管理硕士 | 环境、社会、治理与金融（ESGF） | 非全日制 | |
| 公共管理学院 | 公共管理硕士 | 非全日制 | |
| 高级会计审计学院 | 会计硕士 | 会计与财务精英 | 非全日制 | 
| 信息管理与工程学院 | 工程管理硕士 | 非全日制 | 
我校其他各专业或研究方向均不接受调剂。
二、调剂原则
1．我校非全日制金融硕士专业学位，可接受一志愿报考经济学学科（专业代码前两位为02）下设学术学位专业及专业学位专业和管理学学科（专业代码前两位为12）下设学术学位专业的考生调剂，调剂考生须满足调入专业报考条件，且初试成绩须同时符合调出专业和调入专业在A区的全国初试成绩基本要求（国家线）要求。
2．我校工商管理、公共管理、非全日制会计、非全日制工程管理硕士专业学位，可接受一志愿报考工商管理、公共管理、会计、旅游管理、图书情报、工程管理与审计专业学位硕士的考生调剂，调剂考生须满足调入专业报考条件，且初试成绩同时符合调出专业和调入专业在A区的全国初试成绩基本要求（国家线）要求。
3．相关专业、研究方向报考条件、复试录取方案与咨询方式参考上海财经大学研究生院网站发布的《上海财经大学2026年招收攻读硕士学位研究生简章》《上海财经大学2026年硕士研究生招生复试录取办法》与相关学院2026年招生调剂复试办法执行（详见附件）。
4．我校可接受调剂的相关专业不接受报考退役大学生士兵计划考生、少数民族高层次骨干人才计划考生和参加单独考试（含农村师资计划、强军计划、援藏计划）考生的调剂。
报考“退役大学生士兵”专项计划的考生，初试成绩同时符合调出专业和调入专业在A区的全国初试成绩基本要求（国家线）要求，可通过申请调剂到普通计划，调剂我校相关专业。符合条件的，可按规定享受退役大学生士兵初试加分政策。
三、调剂复试工作安排
2026年“调剂意向采集服务系统”于3月27日开通，“调剂服务系统”将于4月8日开通。
请有调剂意愿且符合条件的考生登录“全国硕士生招生复试调剂服务系统”（网址：https://yz.chsi.com.cn/yztj/；微信公众号：chsiyz），仔细查看有关调剂要求及操作流程，查询我校计划余额信息、调剂录取规则，并填报调剂意向，4月8日起提交调剂志愿。
4月8日后，我校将通过“全国硕士生招生调剂服务系统”发放调剂复试通知。收到调剂复试通知的考生，应在“全国硕士生招生调剂服务系统”接受复试，按要求完成资格审查、参加复试。
四、报考我校调剂至其他招生单位
初试成绩符合全国初试成绩基本要求（国家线）而未达到我校复试分数线的考生，或经我校复试而未被录取的考生，可通过中国研究生招生信息网“全国硕士生招生调剂服务系统”，按照教育部2026年的有关规定，申请其他高校调剂复试。
初试成绩不符合全国初试成绩基本要求（国家线）的考生不能调剂至其他院校。
